# 抗美援朝导览

在同一颗三维地球上，用通俗口播讲解 1950–1953 年抗美援朝战争的烈度、动员、装备与谋略。这是给听众的讲解，不是文献朗诵。

## 本地预览

在项目根目录：

```bash
npm install
npm run dev
```

然后打开带 `?journey=korea` 的本地预览。章一占用 http://127.0.0.1:5173/ ，本线使用单独端口，例如 [http://127.0.0.1:5175/?journey=korea](http://127.0.0.1:5175/?journey=korea)。

不要占用已经在跑的 dev 服务器；若 5173 被占用，换一个空闲端口，并在地址后加上 `?journey=korea`。

默认 `/` 与 `?journey=force` 仍进入第一章「战国」。本目录不改 `src/journey/force/` 下的任何文件。

## 操作

- 必须先点击「播放解说」（浏览器会拦截自动播放）。随后地球会转到各段区域，类型学战争演示与口播 / 段落时钟同步。
- 居中的浅色旧纸作战简报（不规则焦边，平铺在画面正中）随新段落在画面中央展开、收起，并带淡入淡出。插图是印在卷上的类型学故事画，不是旁边另挂的示意图或现场照片。
- 数字键 `0`–`6` 跳转段落；`←` `→` 切换；空格播放或暂停。
- 拖动地球，滚轮缩放。
- 点击战役地点、装备标记或地名，查看短卡片。卡片措辞经过史料审慎处理。
- 「史料与注释」抽屉列出可核对的来源；EN / 中文切换（英文是完整对等文案，不是随文注解）。口播仅为中文，切到英文会暂停语音。
- 「从头播放」从第 0 段重来。`Esc` 先关闭资料或卡片，再退出导览。

## 段落

| # | id | 一句话 |
| --- | --- | --- |
| 0 | hook | 「这不是一场边境摩擦。」新中国决定派出志愿军渡过鸭绿江，并提出烈度、动员、装备、谋略四轴。 |
| 1 | timeline | 从一九五〇年六月爆发，到一九五三年七月二十七日板门店停战：仁川、渡江、五次战役、边打边谈。窄半岛上的高强度现代战争。 |
| 2 | mobilization | 「抗美援朝，保家卫国。」志愿军、全国动员、空袭下的运输线、捐献与医疗队。对照第一章的户籍、粮仓与县制。不编造人数。 |
| 3 | equipment | 初期轻装步兵对联合国军的空、坦、炮优势；后来的米格十五与「米格走廊」；在封锁下维持的补给线。类型学装备，不是馆藏扫描。 |
| 4 | strategy | 第一次战役的隐蔽与冲击；仁川作为麦克阿瑟的战役突然性；五次战役之后的边打边谈。谋略是国家决策，并接到第一章「谋略是一种国家技艺」。 |
| 5 | campaigns | 云山、长津湖（Chosin）、上甘岭（三角山），按需要回到仁川。只示意接近、包围、阵地攻防与撤离。不可视化伤亡。 |
| 6 | close | 停战不是和平条约；分界线停在三八线附近。文献站得住的是渡江的决定与代价、现代动员，以及装备不对称下的战役技艺。比较接口已留下。 |

`BEAT_COUNT` 由 `sites.ts` 的分期表推出，并与 `content.ts` 里 `BEATS.length` 做类型对齐；两者不一致时构建会失败。

## 史学审慎

- 区分文献记载与可核对估计。不编造伤亡或兵力总数，不以区间中值充当事实。
- 口播开场不放置死亡总数。若卡片或「史料与注释」必须出现数字，会注明来源（中国官方战史 / 美国官方战史 / 学者研究），并保留分歧。
- 地球上的战争演示都是类型学示意，标明「示意 / typological」，不是兵力普查，也没有血腥表现。
- 钉位是今地图上的代表性或遗址坐标，会在画面上说明。
- 名称：中国人民志愿军 / PVA，朝鲜人民军，联合国军 / UN Command；仁川、鸭绿江、三八线、板门店、云山（Unsan）、长津湖（Chosin Reservoir）、上甘岭（三角山 / Triangle Hill）、丹东（当时称安东）。

## 比较接口

`comparison.ts` 导出按烈度 / 动员 / 装备 / 谋略四轴排列的类型化对照，供日后合并线使用。第一章的概念标签（户籍、粮仓、县制、青铜弩机、兵书、长平审慎、谋略是一种国家技艺）作为数据复制在本文件中，并注明对应 `src/journey/force/content.ts`。本模块不运行时引用 force，以避免循环依赖。本屏不实现打分式对照 UI。

## 卷面与插图

卷面是 `public/art/korea/brief-sheet.webp`：浅色旧纸、不规则焦边，二十世纪作战文书的质感，但开合方式与章一羊皮纸同一套工艺。插图是 `public/art/korea/` 下的类型学故事画（`.jpg`），用正片叠底印在卷上，并标明「示意 / 类型学」。地球上的地名 Html 标签在本线关闭，以免挡住正中的卷；三维钉位仍可点击。

## 音频

口播 mp3 与 `manifest.json` 在 `public/audio/korea/zh/`，与战国的 `public/audio/zh/` 分开。语音为 `zh-CN-YunyangNeural`，语速 `-8%`，与第一章解说接近。若 mp3 无法播放，则回退浏览器 `speechSynthesis`（`zh-CN`）；再失败则仍可静音浏览地球并阅读文案。

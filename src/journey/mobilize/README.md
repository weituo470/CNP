## 八段

0. **开场** — 倒下以后能多快站起来；三条轴：预案与体制、投送与工程、社会动员；轻扣战国章的「国家机器」。
1. **体制** — 2018 年应急管理部（官方机构改革）、预案、四级响应、国家综合性消防救援队伍、解放军与武警救援、面向民用的国防动员。镜头：北京。
2. **抗洪** — 1998 年长江；部队、民兵、守堤与转移；三峡按官方工程事实写为「提前部署的能力」（不是 1998 年已经投入防洪运行）。镜头：武汉 / 荆江。
3. **汶川** — 2008 年投送与对口援建；官方救援数字均标注来源与时点。镜头：映秀 / 汶川 / 成都一带，钉位为今地图代表性或遗址坐标。
4. **疫情** — 从 SARS 到 2020 年；火神山 / 雷神山官方工期、医疗队、方舱的官方表述。官方公布与外部估计分开标注。镜头：武汉。
5. **预警** — 气象与地震预警（按官方表述）、专业救援、航空救援、中央储备。类型学，不是某一次悲剧。镜头：沿海 / 多点。
6. **重建** — 从安置到重建；汶川对口援建是记载最清楚的案例；交通与电力抢通作为工程动员。
7. **收束** — 灾害仍会发生；现代国家可以把医疗、工程、军队和民间力量迅速集中。为战国、抗美援朝、2026 军力基线留好接口。

地球上的路线、箭头和医院体块均为「示意 / 类型学」。数字凡出现都标明来源，详见导览内「信源与注释」。合并说明见 `MERGE.md`。
